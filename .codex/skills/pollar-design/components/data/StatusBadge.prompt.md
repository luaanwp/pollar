One-line: the pill status label used for statement, sync and reconciliation states.

```jsx
<StatusBadge tone="success" icon="check">Paga</StatusBadge>
<StatusBadge tone="danger" icon="circle-alert">Vencida</StatusBadge>
<StatusBadge tone="warning" icon="clock">Parcialmente paga</StatusBadge>
<StatusBadge tone="info" icon="refresh-cw">Sincronizando</StatusBadge>
```

Pill radius (999) is reserved for badges only. Canonical pt-BR states: Aberta, Fechada, Parcialmente paga, Paga, Vencida, Offline, Sincronizando, Conflito, Previsto, Pendente, Compensado, Conciliado.
