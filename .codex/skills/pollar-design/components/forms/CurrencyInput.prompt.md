One-line: money field that keeps an integer minor-unit model beneath locale formatting and previews installment splits as text.

```jsx
<CurrencyInput label="Valor da compra" valueMinor={123456} onChangeMinor={setMinor} installments={12} />
```

Right-aligned and tabular by default. Paste and keyboard entry are digit-normalised. Negative values render with a true minus sign (−), not a hyphen.
